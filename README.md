# Загрузка прайсов из Excel (1С:Предприятие 8.3)

Внешняя обработка для загрузки прайс-листов из Excel в базу 1С. Создаёт документ «Установка цен номенклатуры» на основе данных из файла.

---

## Демонстрация работы

Код протестирован в. Для песочницы обработка упакована в формат `.sbsl`. Скриншоты работы прилагаются в папке результатов.

---

## Структура проекта

Проект содержит две версии одного кода — для разных сред запуска.

### 1. Для 1С:Предприятие (локальный запуск)

Файлы в корне репозитория — это **Script project** для EDT. Открывается как внешняя обработка (`.epf`) в Конфигураторе или EDT.

| Файл | Назначение |
|------|------------|
| `ExtProcessing_PriceLoader.xml` | Метаданные обработки: реквизиты, макет, форма |
| `PriceLoaderService.bsl` | Общий модуль с бизнес-логикой: чтение Excel, поиск номенклатуры, запись цен |
| `PriceLoaderManagerModule.bsl` | Модуль менеджера: точка входа, связка UI и логики |
| `PriceLoaderObjectModule.bsl` | Модуль объекта (пустой) |
| `MainForm.form` | Форма обработки: выбор файла, предпросмотр, кнопки |
| `Templates/PriceTemplate.xlsx` | Шаблон прайс-листа для скачивания пользователем |

## Как использовать

### Локально (1С:Предприятие)

1. Открыть 1С:Предприятие в режиме «Конфигуратор»
2. Файл → Открыть → выбрать `ExtProcessing_PriceLoader.epf`
3. Нажать F5 для запуска
4. Выбрать Excel-файл, указать тип цены, нажать «Загрузить»

### В песочнице (1С:Фреш)

1. Зайти на [solutions.1c.ru/demo](https://solutions.1c.ru/demo)
2. Выбрать демо-базу (Управление торговлей)
3. Загрузить файл `ExtProcessing_PriceLoader.sbsl`
4. Работать аналогично локальной версии

## Требования

- Платформа 1С:Предприятие 8.3
- Конфигурация со справочниками: **Номенклатура** (с реквизитом Артикул), **Типы цен номенклатуры**
- Документ **Установка цен номенклатуры**

---

## Формат Excel-файла

| Артикул | Наименование | Цена | Валюта |
|---------|--------------|------|--------|
| 001     | Товар 1      | 100  | руб.   |
| 002     | Товар 2      | 200  | руб.   |

Первая строка — заголовки. Данные со второй строки. Пустой артикул — конец данных.
